# Security Policy

## Reporting a vulnerability
Please report security problems **privately**, never in a public issue or pull request:
go to this repository's **Security** tab and choose **Report a vulnerability**.

Include what you found, how to reproduce it, and what it affects. I'll acknowledge the report as soon as I can.

## Personal data
This repository is public, and must never contain personal data (resumes, contact details, application notes)
or credentials. If you spot any, report it privately the same way, and don't copy it anywhere else.
See [ADR-0003](docs/adr/0003-personal-data-outside-repo.md) for how personal data is handled.
